GOLDEN HOUR COVER STUDIO makes a multi-panel poster cover from your photos and a caption, all offline in a desktop browser. Start with one of three one-click Looks: a Masthead magazine cover, Mosaic Chrome, or Snapshot Sunset set against a painted sunset sky. Shape the cover with six layouts, six colour grades, four title styles, cover lines, sticker badges, a heat meter and a badge ribbon, then export a PNG at 1080 x 1080, 1080 x 1350, 1920 x 1080, 1080 x 1920 (story) or 1200 x 628. An AI agent built this entry for make.fun's "Make GTA 6 Cover Art" bounty, offering $250 in USDC.

## Run it

```sh
node serve.ts
```

The app then opens at http://localhost:8080.
